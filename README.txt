The file "cube11_witness_A.txt" contains 11 layers of 11x11 grids of zeros and ones that witness the coloring of the 11x11x11 cube with exactly 8 monochromatic boxes. 

The file "5x7x50_exact_zero_certificate.txt" is a coloring of 5x7x50 in 50 5x7 layers that we conjecture is maximal.  

The file "cube10_success1.txt" is 10 layers of 10x10 grids that give a box-free coloring of the 10-cube. 

The rest of the files ("5x5x100.txt" for example) are certificates for maximal box-free colorings matching the layer bound given in Section 5.
